# Visual Studio Code — Tool Rationale & Usage Standards

## Overview
Visual Studio Code (VS Code) is the **primary development environment** in the NeuByte toolchain.  
It is used for:

- Python API development  
- Markdown standards authoring  
- Jekyll/GitHub Pages editing  
- MySQL integration  
- YAML/JSON editing  
- Git/GitHub workflows  
- project structure management  
- debugging and testing  
- extension‑driven productivity  

VS Code is the central workspace where all NeuByte development and documentation work comes together.

---

## Why VS Code Is Included
VS Code provides several advantages that align with NeuByte’s engineering and documentation strategy:

### ✔ Multi‑Language Support
VS Code supports every language in the NeuByte ecosystem:

- Python  
- SQL  
- Markdown  
- YAML  
- JSON  
- HTML/CSS (for Jekyll)  

This makes it the **single editor** for all roles.

### ✔ Deep GitHub Integration
VS Code integrates directly with GitHub:

- commit  
- push/pull  
- branch management  
- merge conflict resolution  
- GitHub authentication  
- GitHub Issues
