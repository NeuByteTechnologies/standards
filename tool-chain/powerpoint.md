# PowerPoint — Tool Rationale & Usage Standards

## Overview
PowerPoint is an **optional but strategic layout tool** in the NeuByte toolchain.  
It is used for:

- case‑study decks  
- portfolio summaries  
- one‑page project overviews  
- slide‑based storytelling  
- Office‑wide theme consistency (Word + PowerPoint + Excel)  
- exporting clean, pixel‑perfect PDFs  

PowerPoint is *not* used for diagrams, standards, or technical documentation.  
Its role is **presentation and layout**, not content creation.

---

## Why PowerPoint Is Included
PowerPoint provides several advantages that complement the NeuByte documentation ecosystem:

### ✔ Professional Presentation Layer
PowerPoint is ideal for:

- executive‑ready summaries  
- project overviews  
- case‑study decks  
- visually structured storytelling  

These formats are expected by many hiring managers and stakeholders.

### ✔ Office Theme Integration
PowerPoint supports the NeuByte Office Theme:

- Manrope typography  
- NeuByte color palette  
- consistent spacing  
- consistent visual grammar  
- reusable slide masters  

This ensures brand consistency across Word, Excel, and PowerPoint.

### ✔ Pixel‑Perfect PDF Export
PowerPoint exports:

- crisp vector shapes  
- clean typography  
- consistent spacing  
- predictable layout  

This makes it ideal for producing **PDF deliverables** that must look polished.

### ✔ Layout Control
PowerPoint provides layout capabilities that Markdown and Word cannot match:

- grid‑based alignment  
- layered objects  
- precise spacing  
- reusable components  
- visual storytelling  

This makes it the right tool for case‑study decks and portfolio summaries.

---

## Why PowerPoint Is *Not* the Primary Documentation Tool
PowerPoint is intentionally **not** used for:

- standards documentation  
- technical specifications  
- UI specs  
- diagrams  
- data dictionaries  
- RTMs  
- architecture documentation  

These belong in:

- Markdown  
- Word  
- Excel  
- Inkscape  

PowerPoint is for **presentation**, not **documentation**.

---

## When to Use PowerPoint
Use PowerPoint for:

- case‑study decks  
- portfolio summaries  
- one‑page project overviews  
- executive‑level presentations  
- visually structured narratives  
- PDF exports for recruiters or stakeholders  
- Office theme consistency across deliverables  

PowerPoint is the **presentation and storytelling layer** of the NeuByte ecosystem.

---

## When *Not* to Use PowerPoint
Do **not** use PowerPoint for:

- diagrams (use Inkscape)  
- standards (use Markdown)  
- UI specs (use Word)  
- data dictionaries (use Excel)  
- architecture documentation (use Markdown + Inkscape)  
- analytics (use Power BI)  

PowerPoint is not a replacement for technical tools.

---

## File Formats
PowerPoint uses:

- `.pptx` — primary format  
- `.thmx` — theme file  
- `.pdf` — export for deliverables  

Avoid:

- `.ppt` — legacy format  
- exporting diagrams from PowerPoint (use Inkscape instead)  

---

## Workflow Integration
PowerPoint fits into the NeuByte workflow like this:

1. **Document** — write standards in Markdown  
2. **Diagram** — create visuals in Inkscape  
3. **Analyze** — build metrics in Power BI  
4. **Summarize** — create case‑study decks in PowerPoint  
5. **Export** — produce polished PDFs  
6. **Publish** — include in portfolio or GitHub releases  

PowerPoint is the **presentation layer**, not the content layer.
